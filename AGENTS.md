
# AGENTS.md

## Project Scope
Smart Campus Room Availability Checker.

## Allowed Actions
- Read source code and documentation.
- Suggest focused improvements.
- Run safe verification commands.
- Explain all proposed changes.

## Forbidden Actions
- Do not add login or payment systems.
- Do not add external databases or services.
- Do not use real personal information.
- Do not expose secrets.
- Do not delete unrelated files.
- Do not change booking fixtures without approval.
- Do not deploy the application.

## Verification
- Review proposed changes.
- Run available automated checks.
- Record test results and failures.
- Preserve the existing acceptance criteria.

## Human Approval
All AI-assisted changes require human review and approval.

## Background Agent Rules
- Use a separate Git branch or worktree.
- Do not modify the main branch directly.
- Do not perform destructive operations.
- Provide a Git diff and test evidence.
- Require human approval before merging.
