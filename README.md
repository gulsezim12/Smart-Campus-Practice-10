
# Smart Campus Room Availability Checker

## Project Description
This is a React and TypeScript web application for checking the availability of fictional study rooms.

## Features
- Four fictional rooms
- Capacity and equipment filters
- Blocked room handling
- Booking time validation
- Responsive interface
- No real bookings or personal data

## Technologies
- React
- TypeScript
- Vite
- Tailwind CSS

## Installation
1. Open the project folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address shown in the terminal.

## Verification
- `npm run typecheck`
- `npm run lint`
- `npm run build`

The original project did not include an npm test script.

## Project Limitations
This is an educational prototype.
It does not support real bookings, payments, or login.
